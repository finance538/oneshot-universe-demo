ما يُطلبه كل تاجر حسب البوابة

PayTabs: Profile ID · Server Key · Merchant ID (الترميز SAU).

Telr: Store ID · Auth Key · (اختياري) Terminal / Currency.

مدى / Mada: Provider ID · Merchant ID · Terminal ID.

Apple Pay: Merchant Identifier · Certificate · Domain verification.

STC Pay: Merchant Code · API Key · Wallet ID.
